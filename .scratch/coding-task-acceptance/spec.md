# 编码任务验收与恢复
Status: resolved

## 目标
让协作者通过稳定身份找回未完成任务，并让协调者从可验证证据判断为什么还不能验收。

## 已拍定的决策（人类确认，协作方不要重新论证）
### D1 可选的编码任务档案
保留普通讨论和 ACK 通知语义；编码任务另存验收标准、版本绑定的验证证据、spec/quality 审核与阻塞项。缺失、过期、受阻时禁止验收。
### D2 持久恢复
原子保存阶段、负责人、工件引用、审核问题和下一步。恢复前检查当前代码和最新消息，重复请求幂等。
### D3 稳定身份与我的任务
身份独立于工具会话；通过已配置项目查询本人未完成任务，分类 actionable、waiting-peer、waiting-human，兼容旧线程。
### D4 边界
仅后端共享模型、CLI 和只读 API。WebUI 视图/布局必须等用户审批独立原型，不改生产 UI。不执行证据里的命令，不新增凭证设置或 commit/push 授权。

## 范围之外
自动执行任意命令、自动提交/推送、自动合并、生产 UI 视觉修改。
